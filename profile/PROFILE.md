# ZAWYA: Instagram profile kit (@zawya.td)

The Instagram connection **can't** change the profile, so these steps are done in the Instagram app or in a browser: **Edit profile**.

| Field | Value |
|---|---|
| **Profile picture** | `avatar.jpg`: dark, with the symbol large enough to read at small sizes |
| **Name** (searchable) | `زاوية \| ZAWYA` |
| **Username** | Keep `zawya.td`, or change it to the handle you secure on every platform |
| **Category** | Media/News company (or Education) |
| **Bio** (under 150 characters) | See below |
| **Link** | Empty for now; add the website when it's live |

**Bio:**
```
مجلة عربية للتفكير.
فكرة واحدة كل يوم، بدليل ومصدر،
من زاوية لم تنتبه إليها.
فكّر مرة أخرى.
```

**Story highlights:** create them after the first Stories, using `highlights/cover-*.jpg`.

| Cover | Highlight name |
|---|---|
| `cover-1-البداية` | البداية |
| `cover-2-فكّر` | فكّر |
| `cover-3-تاريخ` | تاريخ |
| `cover-4-AI-إنسان` | AI × إنسان |
| `cover-5-سؤال` | سؤال |

**After the launch posts:** pin 01, 02 and 03.

**The hero** has no place on an Instagram profile, which has no banner. It's for:
- the website: `out/zawya-brand/hero/hero-web.png` and the looping video;
- the YouTube channel banner: `hero-youtube.png`;
- the X header: `hero-x.png`.
